# NOTES.md

## 🧠 Overview

This project is a React Native implementation of the "Ready!" AI interview practice app.

The goal is to build a clean, scalable, and pixel-perfect UI based on the provided Figma design.

## ⚙️ Initial Plan

* Use feature-based architecture
* Implement screens step by step (Auth → Home → Session → Settings)
* Use local mock data for all content

## 🚀 Approach

Start with navigation setup and auth flow, then progressively build core screens.
